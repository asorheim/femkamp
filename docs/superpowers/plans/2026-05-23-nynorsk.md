## Task 1: Resume fix — only persist while playing

**Files:**
- Modify: `src/hooks/useGameState.ts`

- [ ] **Step 1: Make the change**

Replace this block:

```ts
  useEffect(() => {
    if (state.status !== "setup") { saveGameState(state); }
  }, [state]);
```

with:

```ts
  useEffect(() => {
    if (state.status === "playing") { saveGameState(state); }
  }, [state]);
```

Rationale: when the last round finishes, `nextRound` calls `clearGameState()` and sets `status:"finished"`. The old effect then re-saved the finished state, undoing the clear, so a reload reloaded the finished game and showed the winner screen. Saving only while `"playing"` lets the clear stick, so a reload after finishing goes to setup. An in-progress game is still saved (resume dialog unchanged).

- [ ] **Step 2: Build + lint**

Run: `npm run build` → expected: `tsc -b` clean + Vite build OK.
Run: `npm run lint` → expected: only the 2 pre-existing errors in `src/components/ui/badge.tsx` and `src/components/ui/button.tsx`; no new errors.

- [ ] **Step 3: Run tests**

Run: `npm test` → expected: 15 passed (unaffected).

- [ ] **Step 4: Commit**

```bash

git commit -m "fix: don't persist finished game so reload returns to setup"
```
